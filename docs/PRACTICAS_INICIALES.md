# Prácticas de los cursos iniciales

Cada curso contiene diez lecciones con tres ejercicios cada una: treinta ejercicios. Las dos primeras lecciones se conservan y se añaden ocho refuerzos. Los identificadores y notas anteriores se mantienen.

Cada ejercicio nuevo tiene un caso propio, tres opciones, una explicación correcta y dos explicaciones de error. Aoi cuenta con intervenciones propias para presentación, pista, acierto, primer fallo y reincidencia. No se alternan manualmente.
